# Vitals

An idle game about growing a rural clinic into a hospital system.

**Play:** https://douglewis4.github.io/vitals/

You run the Emergency department. Patients arrive, and a share of them need
labs — but a small clinic cannot run its own, so those tests are sent to
another facility and earn you nothing. Bringing labs in-house is the first
real thing you buy, and it never quite keeps up with a department that keeps
growing.

Built with TypeScript and Vite. No canvas, no engine — the whole thing is
DOM, CSS and generated SVG.

This repository holds the built site only.
